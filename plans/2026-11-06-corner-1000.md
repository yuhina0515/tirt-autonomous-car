# Per-turn1000-trial stress test

User requests rules alignment and1000 simulations for every bend, using scripts to avoid token waste. Scope is actual layered empty-route core, frozen current headers, local planar geometry extracted from the existing ground-course hypothesis. All204 nonzero directed turning vertices (>0.01degree) included; curve sampling points are not204 distinct named official obstacles. Fresh seeds202611060000+vertex*1000+trial,1000unique trials each. Previous reserved full-lap seeds untouched.

Each window retains up to0.6m arclength before/after the vertex including adjacent bends. Reset at rest with lateral offset±15mm and heading±8degrees; no full-lap history. Physical5ms stepping,5ms sample latency, finite sensor footprint/noise, wheel response and acceleration/grip limits. Actual firmware receives only ADC/time. Source, geometry, seed formula, trial CSV, summaries and reproducibility checks saved.408pilot trials are separate and not pooled.

Uniform assumed ranges: wheel track95..135mm, sensor forward40..85mm, sensor spacing11..18mm, maximum wheel speed0.4..0.85m/s, dead PWM20..60, driven response40..140ms, coast120..350ms, acceleration1.5..4.5m/s2, left/right gains0.9..1.1, battery0.8..1, friction0.3..0.8, ADC Gaussian sigma2..12. These are sensitivity assumptions, not population probabilities or measured vehicle calibration.

Strict local success requires all ordered bisector gates crossed forward within the0.19m corridor, no controller fault/false mission, neither wheel leaving road, body footprint retaining the guide centerline, within15s. V-turn wheel exemption is deliberately not applied to this conservative benchmark; report separately from official rules. Flat geometry omits elevated layers, extra paint, mechanisms, collisions/tipping and full-route mission history. Never use this local test as proof that the complete official course was built or passed.
