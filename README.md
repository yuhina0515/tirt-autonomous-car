# TIRT 自駕車：循跡、尖角與終點停車

**分支最新設定：直道230、彎道外輪125／內輪25或75，尖角外輪125／內輪反轉95。** 依轉向過度回報縮小差速，[目前完整速度表](docs/SPEED_SETTINGS.zh-TW.md)。這是v0.4.0之後的更新，既有Release仍是直道100；[先前傾斜彎調整](docs/TUNING_INCLINE_2026-10-25.zh-TW.md)保留為歷史紀錄。

正式發布：**v0.4.0**。下載及速度設定見 [Release說明](docs/RELEASE_v0.4.0.zh-TW.md)。正式版本標記不代表實車穩定性已驗證；升降台等待依使用者指示改為23.35秒。

2026-10-25 依使用者指示，以原先 self-driving_car 的三感測器／PWM100 程式為基礎重寫，加入尖角轉彎及測試賽道終點停車。

## 使用檔案

- **[升降台流程與設定](docs/LIFT.zh-TW.md)**：依「途中似乎沒有其他十字」的回覆，暫把第1個確認寬白事件視為升降台，停等23.35秒後PWM45離台；等待時間與路段假設未經實車確認。沒有升降台的練習墊須將LIFT_ENABLED改為0。
- **[2026 TIRT 官方規則整理](docs/TIRT_RULES_2026.zh-TW.md)**：依2026-10-25直鏈下載、規則版次2026.09.30整理，含頁碼、完整地圖、關卡要求與現行程式差距。調整正式賽策略前先閱讀。
- **[測試賽道起終點策略](docs/ONE_LAP.zh-TW.md)**：從下方大片白區左側的窄線起點出發；寬白終點持續確認後鎖定停車。最短運行15秒與終點250 ms是候選設定，不是整圈定位。
- [60°／90° 尖角轉彎策略](docs/SHARP_TURNS.zh-TW.md)：最近偏側後失線時樞紐轉向，重新抓回中央線後結束；800 ms 逾時鎖定停車。
- [00000～11111 完整對照表](docs/SENSOR_TRUTH_TABLE.zh-TW.md)：原五感測器設計與目前三感測器版的對應行為。
- **[car.xml](car.xml)**：主程式，包含原比例循跡、尖角樞紐轉向、短缺口直行、升降台停等及終點鎖定停車。
- [car.ino](car.ino)：由這份 XML 使用本機保存的原廠 CAGEBOT 產生器同步匯出。
- [程式說明](car.md)、[硬體紀錄](hardware.md)、[三感測器差異](three_sensor/README.md)：修改前先參考；部分說明保留歷史五感測器設計，現用差異以三感測器說明為準。

控制使用 A4/A3/A2，A5/A1 只輸出原始值；直道PWM230、彎道基準125、TURN_KP100、門檻70。短缺口為PWM70並在側線回來時立即差速拉回；F=8／12向左、F=2／6向右，同側連續15 ms才確認，方向250 ms內失線即轉向，中央線連續80 ms才清除方向。最新反向候選未確認時，不沿舊方向盲轉。沒有套用馬達交換設定或硬編路段右轉；新速度效果尚無新增實車證據。

## 本次移除與保留

先前的低速、交叉與左右馬達交換候選已撤回，歷史可由 Git 找回。目前根目錄主檔依後續明確要求，重新加入尖角策略及照片所示賽道的終點處理，沒有切回那些測試版本。

昨天的 firmware/practice_controller、build.py 與 config.json 保留作 temporal 候選參考，**不是目前主程式**；不要用它們覆蓋根目錄 car.xml。legacy 保留舊來源。
採集與 Hina Web 上傳工具保留，說明見 [LIVE_CAPTURE](docs/LIVE_CAPTURE.zh-TW.md)；它們不是修改策略的前置要求，舊版輸出也不保證符合新採集格式。

本次依使用者要求未執行額外測試，也未燒錄實車。車上韌體狀態與來源分開記錄。

## 後續修改

以 car.xml 原策略為基礎，針對明確的路段行為修改。修改積木後，從 CAGEBOT 同步匯出 Arduino；不要只改 Arduino，也不要使用另一套候選產生器重建本版。
一般循跡保留原規則；依後續要求加入尖角樞紐轉向及轉向逾時鎖定。重寫工具為 `tools/rewrite_car.py`，它讀取保留的舊 XML 並加入上述策略產生新版 XML；Arduino 請由 CAGEBOT 匯出，或使用 `tools/export_car.mjs` 搭配本機原廠產生器。原廠檔案不隨本庫散布。
