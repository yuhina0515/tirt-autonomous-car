# TIRT 自駕車：循跡、尖角與終點停車

**全白後仍在線的澄清**：有方向的寬白彎道採前進100／50差速，不在F14反轉；白線回側邊就一般彎174循跡，該事件真正F0才搜尋。取消前版90 ms寬白反轉。[現行規則](docs/WIDE_VISIBLE_LINE_2026-10-25.zh-TW.md)。

**60度寬白入彎**：保留全白前有效方向，有證據的F14立即啟動尖角；收線前僅在事件起算前90 ms允許F14樞紐轉向，之後補線，避免只慢速直行或反覆旋轉。無證據才走一般寬線。[現行策略](docs/WIDE_CORNER_ENTRY_2026-10-25.zh-TW.md)。

**彎道寬白備援**：CORNER_WIDE_STOP_ENABLED=0，轉彎／收線／缺口的F14逾時改低速補線。該次恢復暫不辨識升降／終點或寬白逾時，中央線穩定80 ms才解除。[現行說明](docs/CORNER_WIDE_FALLBACK_2026-10-25.zh-TW.md)。

**右60度彎補線修正**：失線備援保留合格方向，右45／15、左15／45；方向120 ms後過期，補線重入不刷新。無方向才45／45，失線鎖停仍暫停。[現行補線規則](docs/DIRECTIONAL_LOSS_RECOVERY_2026-10-25.zh-TW.md)。

**暫停失線鎖停**：LOSS_STOP_ENABLED=0；F0持續到原失線期限時改為PWM45／45前進，不再因此鎖定停車。其他升降、終點與故障條件保留；改回1恢復。[設定說明](docs/LOSS_STOP_DISABLED_2026-10-25.zh-TW.md)。

**升降台辨識更新**：F14寬白持續30 ms只建立候選；第一筆離開寬白若直接為F4中央線且無轉向提示，即在當圈停車；若先偏側／失線／轉彎即取消候選。[現行序列](docs/LIFT_CROSS_EXIT_2026-10-25.zh-TW.md)取代下方「寬白立即停等」舊規則。

**彎中寬線處理**：已進入尖角的F14改採共用60 ms低速前進不確定事件，不再於收線時單次鎖停。正常循跡的升降台／終點判斷保留；尚未確認現場「全白」對應F0或F14。[現行說明](docs/CORNER_WIDE_2026-10-25.zh-TW.md)。

**積木載入修正**：回線判斷改先存整數0／1，避免布林條件與數字比較造成CAGEBOT自動拆開接點。已通過原廠Blockly載入後接點完整性檢查並重新匯出Arduino。[修正說明](docs/CAGEBOT_CONNECTION_FIX_2026-10-25.zh-TW.md)。

**Taiwan折點停車更新**：150 ms外側支持期限只限制尚未回線的搜尋；收線短暫F0採固定60 ms前進補線，F10先輸出0並作20 ms確認，穩定有效線15 ms才清除事件。速度與800 ms總期限保留。[現行說明](docs/TAIWAN_CORNER_STOP_2026-10-25.zh-TW.md)覆蓋下方舊停車規則。

**直道／60度更新**：小修正不再清除已累積階段；長修正使用彎道輸出，回中30 ms恢復原階段。外側候選與同側F2／8同時成立即可開始受150 ms期限限制的暫定轉向。[現行說明](docs/STRAIGHT_HOLD_CORNER_ENTRY_2026-10-25.zh-TW.md)優先於下方舊規則。

**90／60度彎修正**：無外側提示時，中間同側候選確認15 ms且達F2／8也提前轉；曾失線後同側單顆回線即用100／20差速收線，相鄰100／50。開始收線後失效不再恢復反轉。[現行說明](docs/CORNER_CAPTURE_2026-10-25.zh-TW.md)覆蓋舊尖角回線基準174。

**低速彎提高45%**：一般彎外輪120→174、內輪10／60→15／87，TURN_KP174；尖角回線前進基準也為174。直道上限230與尖角反轉搜尋150／114保留。[現行速度](docs/CURVE_SPEED_45_2026-10-25.zh-TW.md)優先於下方歷史值。

**第14／15區尖角修正**：外側已確認方向且同側中間最邊緣F=2／8在線時提前啟動尖角，不再等全失線；直道修正保速由80縮為30 ms，回中30 ms確認（總恢復期限60 ms）。速度保留。[完整說明](docs/EARLY_CORNER_2026-10-25.zh-TW.md)優先於下方舊紀錄。

**目前設定**：直道短暫F=6／12修正保留100／150／190／230階段，外輪維持階段PWM、內輪減30；共用80 ms修正期限，回中30 ms才解除，期間暫停升級。一般彎改外輪120／內輪10或60，尖角150／反轉114。[完整設定](docs/STRAIGHT_TRIM_2026-10-25.zh-TW.md)優先於下方歷史紀錄。

**第14段外側輔助**：依使用者選擇，A1／A5新增尖角方向判斷；確認外側證據優先，尚在確認時先停車。僅由中間方向支持的失線搜尋最多150 ms，避免長時間沿錯側反轉；一般循跡F仍用中間三顆。[完整規則與門檻](docs/OUTER_TURN_ASSIST.zh-TW.md)。外側候選會取消直道升速，未證明實車已通過。

**目前直道改四階段**：中央F=4連續0／200／500／900 ms，使用PWM100／150／190／230；偏側或進入其他狀態即重設。彎道與失線限制保留，[現行階段表](docs/STRAIGHT_STAGES.zh-TW.md)覆蓋下方舊斜率升速紀錄。

**第一彎入彎調整**：彎道基準降100、內輪8或50；中央線200 ms後才由100每20 ms加5升速，最高230。尖角反轉搜尋125／95保留，回線前進改100。[目前入彎設定](docs/FIRST_CORNER_2026-10-25.zh-TW.md)優先於下方歷史值，尚無實車通過證據。

**第四彎直衝修正**：已撤回1 ms，方向及回線恢復15 ms；F=4穩定80 ms後才逐步升到230。F=10不再保留原命令，改為鎖定停車；F值明確選轉向，避免等於門檻70時掉入預設高速。全黑無方向時僅PWM45／120 ms缺口處理。[目前輸出規則](docs/RUNAWAY_FIX_2026-10-25.zh-TW.md)優先於下方舊紀錄。

**控制迴圈更新**：預設關閉文字回傳（DEBUG_SERIAL=0）、LED只在狀態改變時更新；尖角／缺口回線改連續1 ms確認。速度設定保留，[詳細說明](docs/CONTROL_LOOP.zh-TW.md)。需要原始輸出時啟用DEBUG_SERIAL，最多每50 ms一筆；控制不以這個回傳頻率執行。

**分支最新設定：直道230、彎道外輪125／內輪25或75，尖角外輪125／內輪反轉95。** 依轉向過度回報縮小差速，[目前完整速度表](docs/SPEED_SETTINGS.zh-TW.md)。這是v0.4.0之後的更新，既有Release仍是直道100；[先前傾斜彎調整](docs/TUNING_INCLINE_2026-10-25.zh-TW.md)保留為歷史紀錄。

正式發布：**v0.4.0**。下載及速度設定見 [Release說明](docs/RELEASE_v0.4.0.zh-TW.md)。正式版本標記不代表實車穩定性已驗證；升降台等待依使用者指示改為23.35秒。

## 使用檔案

- **[升降台流程與設定](docs/LIFT.zh-TW.md)**：依「途中似乎沒有其他十字」的回覆，暫把第1個確認寬白事件視為升降台，停等23.35秒後PWM45離台；等待時間與路段假設未經實車確認。沒有升降台的練習墊須將LIFT_ENABLED改為0。
- **[2026 TIRT 官方規則整理](docs/TIRT_RULES_2026.zh-TW.md)**：依2026-10-25直鏈下載、規則版次2026.09.30整理，含頁碼、完整地圖、關卡要求與現行程式差距。調整正式賽策略前先閱讀。
- **[測試賽道起終點策略](docs/ONE_LAP.zh-TW.md)**：從下方大片白區左側的窄線起點出發；寬白終點持續確認後鎖定停車。最短運行15秒與終點250 ms是候選設定，不是整圈定位。
- [60°／90° 尖角轉彎策略](docs/SHARP_TURNS.zh-TW.md)：最近偏側後失線時樞紐轉向，重新抓回中央線後結束；800 ms 逾時鎖定停車。
- [00000～11111 完整對照表](docs/SENSOR_TRUTH_TABLE.zh-TW.md)：原五感測器設計與目前三感測器版的對應行為。
- **[car.xml](car.xml)**：主程式，包含原比例循跡、尖角樞紐轉向、短缺口直行、升降台停等及終點鎖定停車。
- [car.ino](car.ino)：由這份 XML 使用本機保存的原廠 CAGEBOT 產生器同步匯出。
- [程式說明](car.md)、[硬體紀錄](hardware.md)、[三感測器差異](three_sensor/README.md)：修改前先參考；部分說明保留歷史五感測器設計，現用差異以三感測器說明為準。

一般循跡使用 A4/A3/A2，A5/A1另協助尖角選側；直道PWM230、彎道基準125、TURN_KP100、門檻70。短缺口為PWM70並在側線回來時立即差速拉回；F=8／12向左、F=2／6向右，同側連續1 ms才確認，方向250 ms內失線即轉向，中央線連續80 ms才清除方向。最新反向候選未確認時，不沿舊方向盲轉。沒有套用馬達交換設定或硬編路段右轉；新速度效果尚無新增實車證據。

## 本次移除與保留

先前的低速、交叉與左右馬達交換候選已撤回，歷史可由 Git 找回。目前根目錄主檔依後續明確要求，重新加入尖角策略及照片所示賽道的終點處理，沒有切回那些測試版本。

昨天的 firmware/practice_controller、build.py 與 config.json 保留作 temporal 候選參考，**不是目前主程式**；不要用它們覆蓋根目錄 car.xml。legacy 保留舊來源。
採集與 Hina Web 上傳工具保留，說明見 [LIVE_CAPTURE](docs/LIVE_CAPTURE.zh-TW.md)；它們不是修改策略的前置要求，舊版輸出也不保證符合新採集格式。

本次依使用者要求未執行額外測試，也未燒錄實車。車上韌體狀態與來源分開記錄。

## 後續修改

以 car.xml 原策略為基礎，針對明確的路段行為修改。修改積木後，從 CAGEBOT 同步匯出 Arduino；不要只改 Arduino，也不要使用另一套候選產生器重建本版。
一般循跡保留原規則；依後續要求加入尖角樞紐轉向及轉向逾時鎖定。重寫工具為 `tools/rewrite_car.py`，它讀取保留的舊 XML 並加入上述策略產生新版 XML；Arduino 請由 CAGEBOT 匯出，或使用 `tools/export_car.mjs` 搭配本機原廠產生器。原廠檔案不隨本庫散布。
