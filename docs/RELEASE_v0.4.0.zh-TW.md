# v0.4.0 正式發布

發布類型為正式Release，不標記為Pre-release。此標記是版本交付分類，不代表已驗證實車穩定性、完整一圈或升降台合規。

## 使用檔案

主程式為根目錄`car.xml`，在CAGEBOT開啟；`car.ino`由同一份XML經本機保存的原廠產生器匯出。請勿把`firmware/practice_controller/`的舊temporal候選當成本版主檔。

發布附檔包含主XML、Arduino、完整Git來源ZIP及SHA256SUMS.txt。ZIP只含已提交檔案，不包含本機採集、上傳私碼、私人設定或原廠編輯器。

## 主要行為

- 恢復三感測器基礎，A4/A3/A2控制；A5/A1僅記錄。
- 保留比例轉向，加入尖角樞紐轉向、方向連續30 ms確認、中央線連續80 ms後清除方向。
- 缺口有界直行、寬白事件辨識與終點鎖定。
- 升降台預設是起跑確認後第1個確認的寬白事件；停車、等待、低速離台，同一標記只觸發一次。
- 依使用者要求，升降台等待由**28.35秒減少5秒，改為23.35秒**。

## 速度設定（PWM命令，非實測車速）

| 狀態 | 左輪／右輪設定 |
|---|---|
| 直道F=4 | 前進100／前進100 |
| 左側單顆F=8 | 前進25／前進100 |
| 左側兩顆F=12 | 前進63／前進100 |
| 右側單顆F=2 | 前進100／前進25 |
| 右側兩顆F=6 | 前進100／前進63 |
| 尖角左轉 | 反轉95／前進100 |
| 尖角右轉 | 前進100／反轉95 |
| 短缺口直行 | 前進70／前進70 |
| 寬白區及升降台離台 | 前進45／前進45 |
| 停車、等待、故障或完成 | 0／0 |

一般轉彎內輪使用`100 - abs(sumW)*75/countOn`的整數運算，設定下限5；目前可達的正常轉向圖樣主要輸出25或63。尖角反轉不受這個內輪下限控制。

本版所有現有馬達命令的最高值為**PWM100**，Arduino PWM介面本身為0～255。程式沒有獨立的全域PWM鉗位器；修改參數時應一併維持上限。PWM100不是每秒速度，也不能據此推算圈速。

## 發布狀態與已知限制

- 沒有為本次發布執行額外單元、原生或實車測試，未編譯或燒錄；僅產生同步XML／Arduino及核對來源差異。GitHub既有CI若因推送自行執行，結果須與實車驗證分開。
- 曾回報第14段應右卻左轉約180°後停車；方向確認規則已修正，沒有收到此後成功通過的證據。
- 升降台位置依「途中似乎沒有其他十字」假設，三顆全亮不能唯一識別機構。
- **23.35秒低於官方27秒±5%的時間範圍，且沒有下降停止回授；不能保證完全停止後才離台。**
- 完圈候選仍使用最短15秒及寬白連續250 ms；不具完整路段定位，不能保證不把普通寬線當成終點。
- 沒有升降台的練習墊應將`LIFT_ENABLED`改為0。

規則來源及實作限制見[TIRT規則整理](TIRT_RULES_2026.zh-TW.md)、[升降台流程](LIFT.zh-TW.md)與[起終點策略](ONE_LAP.zh-TW.md)。
