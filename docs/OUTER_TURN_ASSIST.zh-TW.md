# 第14段右尖角：外側A5／A1輔助選側

**Taiwan折點停車更新**：150 ms外側支持期限只限制尚未回線的搜尋；收線短暫F0採固定60 ms前進補線，F10先輸出0並作20 ms確認，穩定有效線15 ms才清除事件。速度與800 ms總期限保留。[現行說明](TAIWAN_CORNER_STOP_2026-10-25.zh-TW.md)覆蓋下方舊停車規則。

**直道／60度更新**：小修正不再清除已累積階段；長修正使用彎道輸出，回中30 ms恢復原階段。外側候選與同側F2／8同時成立即可開始受150 ms期限限制的暫定轉向。[現行說明](STRAIGHT_HOLD_CORNER_ENTRY_2026-10-25.zh-TW.md)優先於下方舊規則。

**90／60度彎修正**：無外側提示時，中間同側候選確認15 ms且達F2／8也提前轉；曾失線後同側單顆回線即用100／20差速收線，相鄰100／50。開始收線後失效不再恢復反轉。[現行說明](CORNER_CAPTURE_2026-10-25.zh-TW.md)覆蓋舊尖角回線基準174。

**第14／15區尖角修正**：外側已確認方向且同側中間最邊緣F=2／8在線時提前啟動尖角，不再等全失線；直道修正保速由80縮為30 ms，回中30 ms確認（總恢復期限60 ms）。速度保留。[完整說明](EARLY_CORNER_2026-10-25.zh-TW.md)優先於下方舊紀錄。

**目前設定**：直道短暫F=6／12修正保留100／150／190／230階段，外輪維持階段PWM、內輪減30；共用80 ms修正期限，回中30 ms才解除，期間暫停升級。一般彎改外輪120／內輪10或60，尖角150／反轉114。[完整設定](STRAIGHT_TRIM_2026-10-25.zh-TW.md)優先於下方歷史紀錄。

使用者再次回報第14段60°尖角應右轉，卻向左轉約180°後停止，並明確選擇讓A5／A1參與尖角方向判斷。這項變更改變之前「外側只記錄」的實驗範圍；不是再把速度或確認時間當成唯一解法。

## 感測器角色

- 車頭朝前，由左到右為A5、A4、A3、A2、A1；這是沿用專案接線紀錄，未重新量測本次實車。
- A4/A3/A2仍決定正常循跡F值與比例位置，F仍為8／4／2權重。
- A5／A1的原始ADC新增尖角方向輔助；不加入正常F，也不直接改變升降台或終點的F=14條件。

## 外側證據與優先序

| 原始外側條件 | 候選方向 |
|---|---|
| 右A1<70，且左A5≥120 | 右 |
| 左A5<70，且右A1≥120 | 左 |
| 兩側同時<70 | 不選左右，清除已確認外側方向 |
| 其他模糊組合 | 不建立新方向；既有確認證據最多保留120 ms |

外側方向須同側連續20 ms才確認；中間F為0、2、4、6、8、12時才考慮，F=10／14不建立外側方向。70與120是本版候選門檻，不是對每顆外側感測器做過的實測校正。

1. 失線F=0時，有最近120 ms內且沒有新反向候選衝突的外側確認方向，優先用它選轉向側，不沿用舊中間方向。
2. 外側正在確認但還沒有答案時，先寫入PWM0等待，最多80 ms，不直接用舊中間方向開始反轉。
3. 探查期間若外側訊號消失而未確認，或80 ms仍確認不了，就故障鎖定；不再回退到舊側盲轉。PWM0仍不代表主動煞車或立即停止滑行。
4. 沒有外側候選時，仍可採用中間的已確認方向開始搜尋；但啟用外側輔助後，這種僅由中間方向支持的搜尋最多150 ms。若尚未回線，也沒有得到外側確認，就停車。
5. 中間方向搜尋開始後的前150 ms內，外側確認可修正一次方向；修正後固定採用該外側方向，不反覆左右切換，也不重設原800 ms總期限。
6. 由外側證據開始的搜尋，仍是原外輪前進125／內輪反轉95，總期限800 ms，回線連續15 ms後退出。

這不是精確角度控制。150 ms只能限制命令持續時間，不能保證車體一定沒有轉到特定角度；同樣也不能保證外側看到的是正確出口，而不是鄰近線或場外亮處。

## 直道提速與其餘流程

出現外側尖角候選或新鮮的確認方向時，取消中央線直道提速，先回到前進基準100。外側證據消失／過期後，才重新累積直道四階段，不能延續先前230。

四階段100／150／190／230與0／200／500／900 ms時間表保留；一般彎外輪100、內輪8或50，缺口45／120 ms，升降等待23.35秒等其他參數保留。外側探查停車時LED為藍色。

## setup 參數

| 參數 | 預設 |
|---|---:|
| OUTER_TURN_ASSIST | 1 |
| OUTER_LINE_THRESHOLD | 70 |
| OUTER_BACKGROUND_THRESHOLD | 120 |
| OUTER_CONFIRM_MS | 20 |
| OUTER_MEMORY_MS | 120 |
| OUTER_PROBE_TIMEOUT_MS | 80 |
| OUTER_OVERRIDE_WINDOW_MS | 150 |

`OUTER_TURN_ASSIST=0`可退回不使用外側的方向選擇；同時取消本次外側專用150 ms支持期限，仍採原800 ms尖角總期限。不要把它誤認成完整五感測器循跡模式。

## 狀態與限制

未取得第14段失敗當下的五顆原始ADC或車體姿態紀錄，不能把先前錯向歸因確認為單一因素；升降／斜坡上的感測高度與外側讀值也沒有本次新增量測。沒有路段定位，未硬編「第14段必須右轉」，也沒有交換全域左右輪或翻轉感測器排列。

XML與Arduino已同步產生，僅靜態檢視輸出差異。依先前指示未執行額外測試、編譯或燒錄，沒有第14段已通過或免疫白字干擾的證據。變更在開發分支，既有v0.4.0 Release未包含。
