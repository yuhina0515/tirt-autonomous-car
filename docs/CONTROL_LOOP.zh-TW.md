# 感測／控制迴圈反應調整

> **外側角色更新**：五顆仍每圈讀取，但A5／A1已新增[尖角方向輔助](OUTER_TURN_ASSIST.zh-TW.md)，不是只記錄；一般F與比例位置仍只用A4/A3/A2。

> **後續直衝修正**：1 ms已撤回；方向、尖角及缺口回線均恢復15 ms，並加入中央穩定與直道升速限制。以下1 ms說明保留為前次變更紀錄，現行以[第四彎修正](RUNAWAY_FIX_2026-10-25.zh-TW.md)為準。

> 使用者已明確要求套用1 ms確認：方向確認、尖角回線及缺口回線均由15 ms改為1 ms。這是狀態確認門檻，不是保證取樣週期；沒有量測實際頻率。相較15 ms，更容易接受瞬間雜訊。

使用者回報偵測速度似乎跟不上。本次先移除循跡迴圈中的非必要I/O，保持直道230、一般彎道外輪125／內輪25或75、尖角外輪125／內輪反轉95。

## 已修改

- 原程式每圈都組合五顆ADC與F的Arduino String，再逐項寫到115200序列埠。改為`DEBUG_SERIAL=0`預設不輸出，也不組合字串，避免持續傳送造成主迴圈負擔。
- 需要原始讀值時把`DEBUG_SERIAL`改為1；同樣格式每50 ms最多輸出一次，正常運行時的標稱上限20筆／秒，不代表20 Hz控制。輸出放在本圈馬達決策之後，仍可能影響下一圈；沒有宣稱完全非阻塞。
- LED只在狀態改變時寫入，不再每圈呼叫NeoPixel更新。正常運行綠色，升降等待／故障／終點藍色，開機等待仍藍色。
- 尖角及缺口回線確認已由圈數改為毫秒，現依使用者要求使用**連續1 ms**。有效圖樣中斷就重做確認；原轉向800 ms、缺口250 ms總期限不重設。1 ms比前版15 ms更敏感，不能視為已排除瞬間雜訊。
- 尖角看到F=4／6／12仍立即以前進差速捕捉線，不必等確認完成才停止反轉；缺口側線回來也仍立即差速修正。

## 目前參數

| 參數 | 值 | 意義 |
|---|---:|---|
| DEBUG_SERIAL | 0 | 預設關閉文字回傳；不是改變感測門檻 |
| TELEMETRY_PERIOD_MS | 50 | 啟用回傳後的最小輸出間隔 |
| TURN_REACQUIRE_MS | 1 | 尖角回線連續確認時間 |
| GAP_REACQUIRE_MS | 1 | 缺口回線連續確認時間 |
| TURN_DIRECTION_CONFIRM_MS | 1 | 偏側方向確認 |

五顆ADC仍每圈讀取，控制只使用A4/A3/A2；A5/A1僅保留原始值。感測閾值70、ADC設定及其他路線狀態沒有調整。直道230與彎道設定見[速度表](SPEED_SETTINGS.zh-TW.md)，升降等待仍23.35秒。

## 判讀限制

可由程式確認的是每圈文字傳送與重複LED寫入已移出常態路徑；尚未量測控制週期、最差延遲或真實漏線原因，不能報稱特定Hz或保證反應足夠。高速度下的轉向、慣性、感測高度或對比也可能造成看似延遲的現象。

XML與Arduino由同一份XML同步產生，只核對匯出差異。依先前要求，本次未執行額外測試、編譯或燒錄。更新在開發分支，既有v0.4.0 Release未包含。
