# 2026-11-02 控制流程精簡候選

使用者回報TAIWAN的60度彎停車時，中間三顆仍位於白面上，要求嘗試精簡並刪除不必要判斷。這僅確認停車位置，沒有確認當時F值、車上韌體或停止來源。本次不是已定位事故根因，也不是實車通過紀錄。

## 本次刪除與合併

| 舊行為 | 精簡後 |
|---|---|
| F2／F8仍有側線即可提前啟動強反轉，含六條入口 | 可見側線一律前進循跡；只有F0配合已確認方向才進入搜尋 |
| 中心來源搜尋另有150 ms未獲支持鎖停 | 刪除該提前期限；搜尋共用800 ms總期限。150 ms只保留作外側修正方向視窗 |
| 一般F14持續900 ms鎖停 | 刪除；F14作為前進通過觀測，不直接因持續時間鎖停 |
| 終點在F14持續250 ms時停；升降台另有寬白候選 | 共用寬白事件觀察器，第一筆離開須直接F4且無轉向提示，才判升降／終點 |
| 多處複製大段失線備援積木 | 一個loss_fallback函式，由各處共用 |
| 完成轉彎仍保留舊候選；收線備援取原入彎方向 | 入彎、完成及備援交接消耗舊候選；收線備援優先取最新turnCaptureSide，中央／未知為0，不回用舊側 |
| 回線資格先算，再改方向 | 未開始收線時才允許外側修正；先選方向再算回線資格 |

缺口遇F14會移交方向並標記寬白恢復，避免下一圈把同一事件重新當普通標記。完成轉彎分支內不可達的F2／F8子分支一併刪除。

## 升降與終點契約

- 先有起跑窄線100 ms確認；無turn、gap、寬白恢復、外側候選或有效外側方向，才能觀察普通寬白標記。
- F14期間只記錄時間並前進。第一筆非F14若是側線、F0、F10或存在轉向證據，取消該候選；稍後回F4不補算。
- F14持續至少30 ms後直接回F4：升降尚未完成時，依既有第1個合格標記停等23.35秒，PWM45離台，連續窄線100 ms完成；離台1.5秒期限保留。
- 升降已完成、全程至少15秒，F14持續至少250 ms後直接回F4，才鎖定終點停車。停車位置由白面內移至白面出口；若終點後沒有中央窄線，這套判斷不會完成終點停車。
- 同一標記須經連續窄線100 ms才可重複觸發。沒有路段定位，彎道若產生相同無方向F14→F4序列仍可能誤判，不能宣稱已唯一辨認關卡。

## 保留的設定與停止

直道100／150／190／230、一般彎174／15或87、搜尋150／反轉114、收線100／20或50保留。中間A4/A3/A2形成F；A5/A1仍只輔助判向。兩個失線停止開關維持0，方向記憶及寬白恢復80 ms置中清除保留。

仍可停止：全程180秒、F10即時零輸出與20 ms事件故障、外側探查暫停、800 ms搜尋期限下非F0／F14故障、缺口期限下未完成回線且非F0／F14故障、收線不接受圖樣、升降離台逾時，以及正常升降／終點。全程期限可能在F14上停止；既有故障也不因F14出現自動解除。PWM0不是主動煞車。

取消900 ms寬白停止後，持續F14可能一直前進至全程180秒；這是本次明確取捨，並非保證方向正確。F14＝三顆ADC低於70，尚未以當次事件資料驗證其物理白面對應。升降23.35秒與既有規則整理的27秒±5%差距保留，未宣稱合規。
