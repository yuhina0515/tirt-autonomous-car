# 目前速度：直道230、降低過度轉向

使用者回報彎道提高50%後轉向過度，因此保留直道230／255，把彎道外輪150降至125、增益150降至100，縮小左右輪差速。尖角外輪150降至125、反轉內輪143降至95。這是轉向力度調整，沒有改失線、終點或升降台判斷。

| 狀態 | 原設定 | 目前設定 |
|---|---|---|
| 中央直道F=4 | 230／230前進 | **230／230前進** |
| 左偏單顆F=8 | 左8、右150前進 | 左25、右125前進 |
| 左偏相鄰F=12 | 左75、右150前進 | 左75、右125前進 |
| 右偏單顆F=2 | 左150、右8前進 | 左125、右25前進 |
| 右偏相鄰F=6 | 左150、右75前進 | 左125、右75前進 |
| 尖角左轉 | 左反轉143、右前進150 | 左反轉95、右前進125 |
| 尖角右轉 | 左前進150、右反轉143 | 左前進125、右反轉95 |
| 缺口直行 | 70／70前進 | 保留70／70前進 |
| 缺口側線拉回 | 25／70或45／70，左右鏡像 | 保留原設定 |
| 寬白區／升降台離台 | 45／45前進 | 保留45／45前進 |
| 停車／升降等待／故障／完成 | 0／0 | 保留0／0 |

一般單顆偏側差速由142縮為100；相鄰兩顆偏側由75縮為50。尖角一前進一反轉的命令幅度和由293縮為220；這些是命令差異，不是量得的角速度。

## 來源參數

```text
SPEED_STRAIGHT = 230
SPEED_CURVE = 125
TURN_KP = 100
SPEED_TURN_INNER_MEDIUM = 8
TURN_OUTER_PWM = 125
TURN_INNER_PWM = 95
```

一般轉彎內輪公式為`max(8, 125 - abs(sumW)*100/countOn)`。尖角回線使用彎道基準125，沒有直接跳到直道230。

目前既有命令最高為**230／255**，約90.2%的PWM占空比；不是225，也不是宣稱已跑到車輛最高實際速度。沒有新增獨立全域鉗位器。

控制仍只用A4/A3/A2，A5/A1僅記錄。方向確認15 ms、中央穩定80 ms、尖角800 ms、缺口250 ms等判定時間保留；升降台等待仍為23.35秒。沒有針對車速變化重新量測角速度、停止距離或失線通過時間，因此這些原時間值不代表已適用新速度。

`car.xml`由`tools/rewrite_car.py`產生，`car.ino`從相同XML經原廠CAGEBOT產生器匯出。本次沒有執行額外測試、編譯或燒錄，尚無新增實車通過證據。

本設定位於開發分支。GitHub正式Release v0.4.0的附檔仍是直道100；它沒有包含目前直道230與彎道125。本次不覆寫該版本標籤或附件。
