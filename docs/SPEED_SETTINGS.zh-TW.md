# 目前速度：直道230、降低過度轉向

**Taiwan折點停車更新**：150 ms外側支持期限只限制尚未回線的搜尋；收線短暫F0採固定60 ms前進補線，F10先輸出0並作20 ms確認，穩定有效線15 ms才清除事件。速度與800 ms總期限保留。[現行說明](TAIWAN_CORNER_STOP_2026-10-25.zh-TW.md)覆蓋下方舊停車規則。

**直道／60度更新**：小修正不再清除已累積階段；長修正使用彎道輸出，回中30 ms恢復原階段。外側候選與同側F2／8同時成立即可開始受150 ms期限限制的暫定轉向。[現行說明](STRAIGHT_HOLD_CORNER_ENTRY_2026-10-25.zh-TW.md)優先於下方舊規則。

**90／60度彎修正**：無外側提示時，中間同側候選確認15 ms且達F2／8也提前轉；曾失線後同側單顆回線即用100／20差速收線，相鄰100／50。開始收線後失效不再恢復反轉。[現行說明](CORNER_CAPTURE_2026-10-25.zh-TW.md)覆蓋舊尖角回線基準174。

**低速彎提高45%**：一般彎外輪120→174、內輪10／60→15／87，TURN_KP174；尖角回線前進基準也為174。直道上限230與尖角反轉搜尋150／114保留。[現行速度](CURVE_SPEED_45_2026-10-25.zh-TW.md)優先於下方歷史值。

**第14／15區尖角修正**：外側已確認方向且同側中間最邊緣F=2／8在線時提前啟動尖角，不再等全失線；直道修正保速由80縮為30 ms，回中30 ms確認（總恢復期限60 ms）。速度保留。[完整說明](EARLY_CORNER_2026-10-25.zh-TW.md)優先於下方舊紀錄。

**目前設定**：直道短暫F=6／12修正保留100／150／190／230階段，外輪維持階段PWM、內輪減30；共用80 ms修正期限，回中30 ms才解除，期間暫停升級。一般彎改外輪120／內輪10或60，尖角150／反轉114。[完整設定](STRAIGHT_TRIM_2026-10-25.zh-TW.md)優先於下方歷史紀錄。

> **外側輔助優先**：A5／A1現已協助尖角選側，外側候選／確認期間取消直道提速；中間來源搜尋若150 ms內既未回線也無外側確認就停止。[現行方向策略](OUTER_TURN_ASSIST.zh-TW.md)覆蓋舊「外側僅記錄」說明。

> **現行直道**：已由斜率升速改為[四階段](STRAIGHT_STAGES.zh-TW.md)：中央連續0／200／500／900 ms對應100／150／190／230，離開中央即重設。以下較早「每20 ms加5」僅作歷史紀錄；彎道外輪100／內輪8或50保留。

> **第一彎最新設定**：中央起步100，穩定200 ms後每20 ms加5，最高230；一般彎外輪100／內輪8或50。尖角搜尋仍125／反轉95，回線前進基準降100。[第一彎調整](FIRST_CORNER_2026-10-25.zh-TW.md)優先於下方前版125等數字。

> **現行覆蓋**：230是中央線穩定後的逐步升速上限，起始125；缺口由70改45、總期限由250改120 ms，側線捕捉改20／45或30／45；F=10改鎖定停止，1 ms確認恢復15 ms。見[第四彎直衝修正](RUNAWAY_FIX_2026-10-25.zh-TW.md)，下方舊缺口值與瞬時直道230不再適用。

> 控制迴圈另已減少I/O開銷；預設DEBUG_SERIAL=0，回線連續確認改為1 ms。速度數值保留，見[控制迴圈](CONTROL_LOOP.zh-TW.md)。

## 來源參數

```text
SPEED_STRAIGHT = 230
SPEED_CURVE = 125
TURN_KP = 100
SPEED_TURN_INNER_MEDIUM = 8
TURN_OUTER_PWM = 125
TURN_INNER_PWM = 95
```

一般轉彎內輪公式為`max(8, 125 - abs(sumW)*100/countOn)`。尖角回線使用彎道基準125，沒有直接跳到直道230。

目前既有命令最高為**230／255**，約90.2%的PWM占空比；不是225，也不是宣稱已跑到車輛最高實際速度。沒有新增獨立全域鉗位器。

控制仍只用A4/A3/A2，A5/A1僅記錄。方向確認1 ms、中央穩定80 ms、尖角800 ms、缺口250 ms等判定時間保留；升降台等待仍為23.35秒。沒有針對車速變化重新量測角速度、停止距離或失線通過時間，因此這些原時間值不代表已適用新速度。

`car.xml`由`tools/rewrite_car.py`產生，`car.ino`從相同XML經原廠CAGEBOT產生器匯出。本次沒有執行額外測試、編譯或燒錄，尚無新增實車通過證據。
