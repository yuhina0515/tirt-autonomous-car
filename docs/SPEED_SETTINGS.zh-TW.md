# 目前速度：直道230、彎道提高50%

依使用者要求，直道由150提高至230／255；彎道在上次外輪100的基礎上提高50%。一般彎道的內輪與增益同比調整，保留原先差速比例；尖角樞紐轉向也納入本次彎道調整。這是PWM命令調整，並非實際車速增加50%的量測結果。

| 狀態 | 原設定 | 目前設定 |
|---|---|---|
| 中央直道F=4 | 150／150前進 | **230／230前進** |
| 左偏單顆F=8 | 左5、右100前進 | 左8、右150前進 |
| 左偏相鄰F=12 | 左50、右100前進 | 左75、右150前進 |
| 右偏單顆F=2 | 左100、右5前進 | 左150、右8前進 |
| 右偏相鄰F=6 | 左100、右50前進 | 左150、右75前進 |
| 尖角左轉 | 左反轉95、右前進100 | 左反轉143、右前進150 |
| 尖角右轉 | 左前進100、右反轉95 | 左前進150、右反轉143 |
| 缺口直行 | 70／70前進 | 保留70／70前進 |
| 缺口側線拉回 | 25／70或45／70，左右鏡像 | 保留原設定 |
| 寬白區／升降台離台 | 45／45前進 | 保留45／45前進 |
| 停車／升降等待／故障／完成 | 0／0 | 保留0／0 |

PWM必須是整數：5×1.5=7.5取8，95×1.5=142.5取143。彎道外輪100→150、相鄰內輪50→75。

## 來源參數

```text
SPEED_STRAIGHT = 230
SPEED_CURVE = 150
TURN_KP = 150
SPEED_TURN_INNER_MEDIUM = 8
TURN_OUTER_PWM = 150
TURN_INNER_PWM = 143
```

一般轉彎內輪公式為`max(8, 150 - abs(sumW)*150/countOn)`，由原曲線基準100、增益100、下限5同比調整。尖角回線使用彎道基準150，沒有直接跳到直道230。

目前既有命令最高為**230／255**，約90.2%的PWM占空比；不是225，也不是宣稱已跑到車輛最高實際速度。沒有新增獨立全域鉗位器。

控制仍只用A4/A3/A2，A5/A1僅記錄。方向確認15 ms、中央穩定80 ms、尖角800 ms、缺口250 ms等判定時間保留；升降台等待仍為23.35秒。沒有針對車速變化重新量測角速度、停止距離或失線通過時間，因此這些原時間值不代表已適用新速度。

`car.xml`由`tools/rewrite_car.py`產生，`car.ino`從相同XML經原廠CAGEBOT產生器匯出。本次沒有執行額外測試、編譯或燒錄，尚無新增實車通過證據。

本設定位於開發分支。GitHub正式Release v0.4.0的附檔仍是直道100；它沒有包含直道230與彎道150。本次不覆寫該版本標籤或附件。
