# 第一彎已有轉向但仍衝出：降低入彎速度

> 後續使用者要求直道改為[四階段提速](STRAIGHT_STAGES.zh-TW.md)，已取代本文件的每20 ms加5；彎道基準100、內輪8／50等其他設定保留。

使用者確認使用本機最新c9e7c9d，第一彎有轉向跡象仍衝出。前版在中央線80 ms後，可由125以每10 ms增加10的方式升到230；一般彎道相鄰側線的內外輪為75／125。這些程式設定已確認，但缺乏該次ADC及馬達／姿態紀錄，不能據此確認唯一物理原因。

本次降低入彎能量並加大相鄰側線的轉向比例，不硬編第一彎方向，也不再縮短確認時間。

| 項目 | 前版 | 本版 |
|---|---:|---:|
| 直道最高設定 | 230 | 保留230 |
| 剛進中央線時的速度 | 125／125 | 100／100 |
| 升速前連續中央線 | 80 ms | 200 ms |
| 升速步階 | 每10 ms加10 | 每20 ms加5 |
| 一般彎外輪 | 125 | 100 |
| 單顆側線內輪 | 25 | 8 |
| 相鄰兩顆側線內輪 | 75 | 50 |
| 一般轉向增益 | 100 | 保留100 |
| 尖角反轉搜尋 | 外輪125／內輪反轉95 | 保留 |
| 尖角回線前進基準 | 125 | 100 |

理想上，即使中央線全程穩定，也要至少約700 ms才會由100升到230；實際迴圈較慢時只會更久，不會補跳步。每次偏側、失線或搜尋都重設中央線升速記憶。程式沒有前視感測器，這不是在彎道出現前量到距離後煞車；高速慣性及滑行仍可能存在。

方向與回線確認維持15 ms。F=10／未分類正常圖樣故障鎖定、無方向缺口45／120 ms、尖角800 ms、升降等待23.35秒與終點規則全部保留。ADC閾值70與感測器極性沒有更動。

XML與Arduino已同步產生，只有靜態檢視匯出差異；依先前指示未執行額外測試、編譯或燒錄，尚無第一彎已通過的證據。更新在開發分支，既有v0.4.0 Release未包含。
