# 直道分階段提速

> **外側尖角提示**：外側出現候選或有效確認方向時，即使中央F=4也先回到100並取消提速階段；證據消失／過期後才重新累積。見[外側輔助](OUTER_TURN_ASSIST.zh-TW.md)。

依使用者要求，把原本每20 ms加5的斜率升速，改為四段固定PWM。仍只在正常循跡且F=4（只有中央A3在線）持續穩定時，才累積同一段直道的時間。

| 階段 | 中央線連續穩定時間 | 左右輪PWM |
|---|---|---:|
| 1 | 0～未滿200 ms | 100／100 |
| 2 | 200～未滿500 ms | 150／150 |
| 3 | 500～未滿900 ms | 190／190 |
| 4 | 900 ms以上 | 230／230 |

時間全部從最近一次進入中央F=4開始，不是每階段另加200、500、900 ms。由高階段條件往低階段判斷，邊界時間屬於下一階段；這些是候選時間值，未經實車圈程或距離量測。

## 重設與優先序

- 任一次偏側、失線、分裂圖樣、寬白區，或進入尖角、缺口、升降、停止／完成等狀態，都重設直道階段。
- 回到正常中央F=4後，從100重新開始，不能沿用先前的230。
- F=10／未分類正常圖樣仍故障鎖定；F=0仍由有界尖角或45／120 ms缺口狀態處理，沒有預設高速直行。
- 一般彎道仍為外輪100、內輪8或50；尖角搜尋外輪125／內輪反轉95。方向／回線確認15 ms、升降等待23.35秒等設定保留。
- 階段PWM不超過SPEED_STRAIGHT（目前230）。這不是感測器取樣週期，也不會跳過每圈感測器讀取。

階段切換是離散速度命令，較前版斜率升速會有更大的單次變化；短直道也可能尚未到後段就開始轉彎。沒有前視距離或輪速量測，仍不能保證每個彎前都已完成實際減速。

## setup 參數

```text
SPEED_CURVE = 100              # stage1 and ordinary curve base
STRAIGHT_STAGE2_MS = 200
STRAIGHT_STAGE2_PWM = 150
STRAIGHT_STAGE3_MS = 500
STRAIGHT_STAGE3_PWM = 190
STRAIGHT_STAGE4_MS = 900
SPEED_STRAIGHT = 230           # stage4 and straight ceiling
```

XML及Arduino已由同一XML同步產生。依先前要求，未執行額外測試、編譯或燒錄，沒有新增實車通過證據。更動在開發分支，v0.4.0 Release未包含。
