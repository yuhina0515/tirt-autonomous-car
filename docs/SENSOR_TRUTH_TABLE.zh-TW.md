## 位元定義

由車頭朝前的方向判斷，感測器由左至右為 **A5、A4、A3、A2、A1**。

```text
左側                    右側
 A5   A4   A3   A2   A1
 16    8    4    2    1

F = 16×A5 + 8×A4 + 4×A3 + 2×A2 + A1
```

`1` 表示讀值 `< LINE_THRESHOLD`（70），`0` 表示未達此在線條件。這是程式的低讀值編碼，不直接用黑／白命名；舊文件的黑線用語與白線練習墊紀錄並不一致。

下表假設讀值沒有恰好等於 70，因為轉向分支另有嚴格 `>70` 比較；等於門檻時不能只憑五位元完全推斷分支。

### 表格以外的狀態規則

- **路口最優先**：F 為 15、23、27、29、30、31 時，設定 `crossCount=30` 並直走；離開後每圈遞減，在倒數歸零前任何 F 都會直走。因此表中的轉彎、雜訊、失線行為會被路口倒數覆蓋。
- **外側濾波**：五感測器版本會排除與內側主線隔開的孤立 A1／A5。因此原始感測器圖樣不一定等於本表的判斷圖樣；例如原始 `01001` 可先被濾成 `01000`，原始 `10010` 可先被濾成 `00010`。
- **失線計數**：從 `whiteCount=0` 開始，F=0 前 40 圈只遞增計數並維持原命令，第 41 圈才寫入兩輪 PWM=0。F>0 會清零計數。這不是永久停車鎖定，重新出現有效圖樣後仍可能恢復馬達輸出。
- **雜訊**：F=10、17 不更新馬達；F=27 已被路口分支先處理，不能列成實際 Error。
- 圈數沒有固定毫秒長度；本表不沿用舊文件約 0.15／0.2 秒的估算。

比例內輪計算使用權重 `A5=-2、A4=-1、A3=0、A2=1、A1=2`：

```text
innerSpeed = max(5, 100 - (abs(sumW) * 75) / countOn)
```

除法先做整數截斷，所以 A4+A3 或 A3+A2 的內輪為 `100-(75/2)=63`。指定舊文件曾舉例為 62，本表依既有 Arduino 運算順序寫為 63。
