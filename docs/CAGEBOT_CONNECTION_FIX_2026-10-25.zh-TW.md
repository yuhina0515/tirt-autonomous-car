# CAGEBOT積木接點修正

使用者載入上一版XML時出現「這個積木不正確連接到其它積木上」。已用本機原廠Blockly重現：載入後處理onchange事件，v5_00329與v5_00372從父積木v5_00328脫離。

原因為將布林回線條件直接與數字0比較；原廠比較積木的輸入型別檢查會拆開不相容接點。上一版僅匯入後立即匯出，未等待Blockly處理載入事件，因而漏掉接點脫離。

現在先依回線布林條件設定整數turnCaptureVisible為0或1，再使用整數比較判斷未回線與回線。保留上一版的控制意圖、PWM、確認時間與狀態策略。

匯出工具新增載入後事件等待及逐積木父接點比對；任一接點脫離或載入警告即中止，不寫入Arduino。舊XML可重現失敗；修正版XML通過此匯入完整性檢查，並重新匯出car.ino。這是針對使用者回報的檔案載入問題作必要確認，未執行車輛行駛測試、Arduino編譯或燒錄。

請重新匯入這次的car.xml，先前已載入並拆開的工作區不會自行修復。既有v0.4.0 Release未變更。
