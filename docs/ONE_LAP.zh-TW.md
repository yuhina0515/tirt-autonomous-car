# 測試賽道：左側起點出發，大白區終點停車

依使用者提供的賽道照片與位置說明：**照片下方大片白區是終點，其左側白線是起點**。把車放在起點窄線上，車頭朝離開終點、沿賽道前進的方向；釋放再按原有開機啟動鈕開始。這份程式不從大片白區起跑。

## 本版行為

1. 一般循跡沿用 A4/A3/A2 比例轉向，PWM 上限100；A5/A1 僅輸出原始值。
2. 窄線連續100 ms 後，標記已進入循跡。從按鈕啟動後的第一圈主迴圈開始計時，前15秒不允許觸發終點。
3. 遇到三顆全在線 F=14，兩輪以 PWM45 前進。已進入循跡、運行至少15秒且 F=14 連續250 ms，才判定大片白區終點。
4. 終點兩輪 PWM=0、LED藍色並鎖定；重新看見線不會啟動，重設／重新上電後才能再次按鈕出發。
5. 一次全亮持續900 ms 仍未形成終點條件，或整次運行達180秒，鎖定停車。

這是以**最短運行時間與寬白區持續時間**辨識終點的候選策略，沒有里程計或路段計數，不能證明車子已依指定路線跑滿整圈。交叉線若也產生足夠長的 F=14，仍可能誤停；15秒與250 ms 都不是由照片量出的實車數值。到達終點所需時間少於15秒時，也不會被正常判成完圈。

## 虛線與尖角

- 中央線 F=4 會清掉舊的尖角方向；F=6／12 的一般雙感測器修正不再單獨建立尖角方向。
- 只有 F=8 或 F=2 記錄明確偏側，且250 ms內失線，才進入原有左／右樞紐轉向。轉向800 ms超時仍鎖定停車。
- 沒有上述方向證據的 F=0 改為兩輪 PWM70 直行跨缺口，總期限250 ms。連續3圈窄線後恢復循跡；看見寬白區則交回寬線／終點處理。期限不因短暫線片段重設，逾時鎖定停止。
- 三顆感測器仍不能保證把所有虛線缺口、白字與尖角分開；本次沒有聲稱已觀察到原地打轉故障。

## 參數

| setup 參數 | 值 | 用途 |
|---|---:|---|
| DEPART_CONFIRM_MS | 100 | 連續窄線確認 |
| MIN_LAP_MS | 15000 | 終點判斷開放前的最短運行時間 |
| FINISH_CONFIRM_MS | 250 | 連續 F=14 的終點確認時間 |
| WIDE_PWM | 45 | 寬線區前進 PWM |
| WIDE_TIMEOUT_MS | 900 | 單次寬線事件最長時間 |
| MAX_LAP_MS | 180000 | 整次運行上限 |
| GAP_PWM | 70 | 短缺口直行 PWM |
| GAP_TIMEOUT_MS | 250 | 單次短缺口總期限 |

`car.xml` 與 `car.ino` 由同一份 XML 同步產生；修改來源為 `tools/rewrite_car.py`。原舊檔仍保留在 `legacy/`。

依使用者要求，本次沒有執行測試、編譯或燒錄。上述限制是目前程式的判定方式，不是額外測試要求。PWM=0移除驅動，車子仍可能滑行；沒有量測終點停車位置或實車圈程。
