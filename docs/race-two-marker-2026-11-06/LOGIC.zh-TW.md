# 32種感測排列與任務優先順序

位元由左至右 **A5、A4、A3、A2、A1**。1代表判定白線，0代表背景。ADC<70進入白、ADC≥100離開白、70..99保持前態；各顆門檻可獨立調整。初始前態為黑。低ADC為白須以實物採集核對。

兩層共用同一份位元狀態，只有任務層可以計數關卡。沿用native循線核心的三顆寬白升降／終點判斷已在獨立候選停用。

## 所有排列共用的優先順序

1. 手動停止、故障或終點鎖定：馬達0；任何感測排列都不能重啟。
2. 運行達360秒，或控制迴圈間隔超過100ms：故障鎖停。
3. 升降等待：所有32排列都保持馬達0、事件數1，確認後停等27000ms。
4. 離台：45/45；同一片五白不計數。必須00100連續100ms才進入升降後；1500ms期限先於晚到的回線判斷。
5. 升降前／升降後遇11111：第一筆就馬達0，連續30ms才計數。首次→停等；第二次→終點鎖停。中斷就重計確認時間。
6. 其他排列交給循線層。中央無線／分裂／寬白的不確定預算800ms，只有30ms連續窄線才清除；單筆閃線不能延長。原循線分裂20ms故障仍保留。
