# v0.3.1-rc.1 低速跑道分段測試

燒錄 **`firmware/field_low_speed/field_low_speed.xml`**。
這份 XML 已填入 2026-10-25 實測校正並啟用驅動；不需再改 `configReady`。
上電不會自動啟動；先釋放按鈕，再按一次開始，運行中再按一次停止。
每次運行最長 60 秒，超時也會停止。

本版用於從窄白線開始的直線、左右彎及銳角分段測試。
**請將中央 A3 放在窄白線上啟動，不能從大片全白區啟動。**
自動起終點判斷暫時關閉；完成分段調校後再準備全白起點與整圈版本。

## 速度與尋線

- 直線基準 PWM 60，彎道基準 45，所有輸出上限 70。
- 最近可信位置偏邊後全黑：內輪停止、外輪 PWM 50 向該側尋線，最長 650 ms。
- 最近位置居中後全黑：PWM 35 短暫直行，最長 200 ms。
- 一般分裂、低對比與跳變：共享該次事件固定期限；未持續找回可信線就停止。
- 仍用 A4/A3/A2 控制，A5/A1 只記錄。故障後不自行重啟。

PWM 是命令值，不是實測車速。PWM=0 不是主動煞車。
低 PWM 下馬達可能起步不足，需架空與落地各確認一次，不要用手推動正在運行的車。

## 操作次序

1. USB 連接，使用 CAGEBOT 開啟 `field_low_speed.xml` 並燒錄。
   Arduino IDE 則使用同資料夾 `.ino`，板子為 Nano / ATmega328P (Old Bootloader)。
2. 輪子架空，用白線分別對準中央、左、右感測器。按鈕開始後確認輪向與轉向，再按鈕停止。
3. 關閉序列監控器，拔掉 USB，車子用電池供電。
4. 將車放在窄白線直線段，中央 A3 對準白線，釋放再按按鈕開始。
5. 依序測直線、左彎、右彎，再測單個 90°／60°角。每段先單獨測，不直接跑整圈。
6. 用錄影記錄啟動、輪向、角落失線與重新取得白線；記錄電池與感測器高度。
   藍牙恢復穩定後可用 `Start-LiveCapture.cmd`、COM5／9600、TRACK 記錄。
   USB COM7／115200 可架空記錄，落地不要拖著 USB 線跑車。

發生持續偏離或超時停止時，記下位置、方向及車輪是否有轉動，再調一個參數重試。
操作電腦、結束採集或斷開連線都不會停止車子；用實體按鈕或電源停止。
