## 實驗與採用規則

1. 固定完整來源、參數、模型、路線和裁判；每次只改一個主要因素，保留未修改的對照及全部失敗。主程式、根目錄rollback及穩定標籤不由實驗覆蓋。
2. 已查看的2026110711～715已成診斷資料，不再當未見驗證。調整完成前另行宣告新驗證種子／條件；不得從不同版本湊五次成功。訓練仍須通過物理ADC來源與實際核心prefix審核。
3. 先檢查定向反證，再跑完整路線；合法覆線、方向、關卡及終點每項都要過，圈時才有比較意義。降低失敗率優先於單次最快紀錄。
4. 模型連續五次合法完成只是模型門檻。正式幾何／機構與車身、馬達、感測延遲未核實前，不列為官方驗收；實車另保存燒錄manifest、原始資料、影片、電池和高度。
5. 實車先馬達關閉校正、架空確認方向，再低速分段與整圈。提高速度後重新檢查左右彎、文字、失線、停車距離及機構；PWM不是m/s，零PWM不是主動煞車。
