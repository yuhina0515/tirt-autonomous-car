# 直道小修正保留階段、彎道增加20%

依使用者回報，直道的小幅修正不再立刻退回起步階段。正常循跡中，F=4建立直道階段後，短暫F=6／12使用目前階段PWM作外輪，內輪減30；例如230階段為230／200，左右依偏側鏡像。這是保留速度階段，差速仍會降低兩輪平均PWM。

## 階段與重設

- 中央線累積0／200／500／900 ms，對應100／150／190／230。小修正與回中確認期間暫停累積，不會邊偏側邊升級。
- 一次小修正事件共用80 ms期限；回到F=4連續30 ms才解除事件，短暫回中不能反覆重設期限。未及時回中即重設階段，偏側時切回一般彎道輸出。
- F=2／8明顯偏側、失線、外側尖角提示或其他控制狀態仍立即重設。沒有先建立直道階段的F=6／12使用一般彎道輸出。

## 現行PWM表

| 狀態 | 左輪／右輪命令 |
|---|---|
| 中央直道 | 100／100、150／150、190／190、最高230／230 |
| 直道短暫左修正F=12 | 目前階段減30／目前階段 |
| 直道短暫右修正F=6 | 目前階段／目前階段減30 |
| 一般左彎F=8／12 | 10／120 或60／120 |
| 一般右彎F=2／6 | 120／10 或120／60 |
| 尖角左轉搜尋 | 左反轉114／右前進150 |
| 尖角右轉搜尋 | 左前進150／右反轉114 |
| 尖角回線前進 | 基準120，依偏側差速 |
| 無方向缺口／升降離台 | 45／45 |

一般彎外輪100→120、內輪8→10（9.6取整）或50→60；尖角搜尋125→150、反轉95→114。TURN_KP由100→120，維持原本差速比例。這是PWM命令增加20%，不是量測車速增加20%。目前命令最高230／255；升降等待仍23.35秒。
