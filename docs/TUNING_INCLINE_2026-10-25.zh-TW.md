# 傾斜彎道與直道150調整

使用者回報傾斜彎道轉向不足，有時失線後停車，並要求直道PWM150。這次以分開直道／彎道速度、加強差速與恢復抓線處理回應，不改感測器範圍或升降台23.35秒等待。

## 目前速度

| 狀態 | 左輪 | 右輪 |
|---|---:|---:|
| 中央直道F=4 | 前進150 | 前進150 |
| 左側單顆F=8 | 前進5 | 前進100 |
| 左側相鄰F=12 | 前進50 | 前進100 |
| 右側單顆F=2 | 前進100 | 前進5 |
| 右側相鄰F=6 | 前進100 | 前進50 |
| 尖角左轉搜尋 | 反轉95 | 前進100 |
| 尖角右轉搜尋 | 前進100 | 反轉95 |
| 缺口中尚未抓線／中央回線 | 前進70 | 前進70 |
| 缺口中左側回線F=8／12 | 前進25／45 | 前進70 |
| 缺口中右側回線F=2／6 | 前進70 | 前進25／45 |
| 寬白區／升降台離台 | 前進45 | 前進45 |
| 停車／升降等待／故障／完成 | 0 | 0 |

以上是PWM命令，不是實測車速。**目前現有輸出最高為150**，硬體介面範圍0～255；沒有另外新增全域鉗位器。

## 差速與回線改動

- 新增`SPEED_CURVE=100`，`SPEED_STRAIGHT`改為150；一般彎道的外輪與比例計算不再使用直道速度。
- `TURN_KP`由75提高為100。內輪計算改為`max(5, 100 - abs(sumW)*100/countOn)`，因此單顆偏側由25降到5，相鄰兩顆偏側由63降到50。降低內輪以加大差速，不把外輪同步提高到150。
- 尖角方向連續確認由30 ms縮短為15 ms，較短的偏側觀測也有機會留下方向；中央線清除80 ms、方向有效期250 ms及衝突候選取消舊方向的規則保留。更短確認也可能增加雜訊誤判，沒有宣稱排除所有錯向。
- 尖角搜尋達最短30 ms後，F=4、6、12都可開始回線確認；第一次看到這些圖樣就停止內輪反轉，改為不超過彎道100的前進差速。連續3圈確認後退出，避免只有精確F=4才允許結束。
- 缺口狀態看到側線時立即使用25／70或45／70的前進差速拉回，不再等待3圈期間仍一律70／70直行。
- 尖角800 ms、缺口250 ms、升降離台1500 ms的固定期限及故障鎖定保留，沒有單純延長盲走時間。若未取得可確認的線，仍會停車。

全黑也可能來自坡上感測高度或對比變化；目前沒有該次原始資料，所以這是針對已知控制限制的調整，不能確認失線根因或宣稱傾斜彎已通過。內輪PWM5在坡上能否有效運轉、直道150的實際效果，都尚無新增實車驗證。

## 檔案與發布

`tools/rewrite_car.py`產生主`car.xml`，再用原廠CAGEBOT產生器匯出`car.ino`。只核對產生檔差異，依先前指示未執行額外測試、編譯或燒錄。

本次更新位於開發分支；已發布的v0.4.0仍保留原PWM100內容，不覆寫其標籤或附檔。使用本次調整請開啟分支最新的根目錄`car.xml`。
